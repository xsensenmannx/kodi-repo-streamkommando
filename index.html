STREAM KOMMANDO

Kodi Repository · Version 1.10.2

Ein Repository, drei Add-ons: gemeinfreie Filme aus dem Internet Archive, Videos der NASA, freie Clips von Wikimedia Commons und die Blender Open Movies – mit Sammlungen, Suche, Qualitätsauswahl und Download-Manager. Keine fremden Portale, keine Bezahlschranken.

Installation in Kodi

  1. Diese Seite als Quelle hinzufügen: Einstellungen → Dateimanager → Quelle hinzufügen, URL https://xsensenmannx.github.io/kodi-repo-streamkommando.
  2. Add-ons → Aus ZIP-Datei installieren → Quelle öffnen → zips/repository.streamkommando/repository.streamkommando-1.3.0.zip.
  3. Aus Repository installieren → Stream Kommando Repository → Video-Add-ons → Stream Kommando.

Was drin ist

Filmarchiv

Acht Sammlungen mit über 60.000 Filmen, sortierbar nach Downloads, Titel oder Jahr.

Qualitätsauswahl

Auflösung, Format und Dateigröße zur Auswahl – oder automatisch das Beste.

Zufallsfilm

Ein Klick, ein zufälliger Film aus dem Archiv.

Eigene Streams

Ein Ordner mit .strm- und .m3u-Dateien, auch aus Unterordnern.
